# 编辑器提示框与翻译队列修复

用户报告潜艇编辑器的物品名称/简介保持英文。本机桥接文件同时出现新请求与旧响应编号，桌面正在处理包含大量已有中文的旧批次。

本次修改：

- 英文到简体/繁体中文时，含汉字文本在游戏采集、桌面接收、翻译调度与网络入口过滤。混合中英文本也保留，不拆开重译；其他语言对不使用此规则。
- 桌面忙碌时仍读取最新请求，使用会话编号取消旧会话任务；新会话移除旧采集记录，保留项目可复用译文。
- 每次游戏请求最多 64 条（按用户要求由 16 提高），桌面每次调度最多 4 条、最多 2 个联网请求并发。当前提示框优先于后台预加载；失败条目本会话不无限重试。增加采集批量减少文件交换次数，不意味着免费接口能同时完成 64 条。
- 接入实际游戏 DLL 中公开的 GUIComponent.DrawToolTip 的 RichString/Rectangle 重载，逐行处理名称与简介并保留颜色标记。停止时移除该补丁。

Windows Python 3.12.14：76 项测试中 75 通过、1 项因符号链接权限跳过。实际安装的 MoonSharp 执行 19 项隔离检查通过，包含富文本提示框、等待中紧急请求和 700 个语言键的有界队列。真实 Tk 事件循环在 100%/150% 字体 DPI 检查通过，新增忙碌时会话切换、最新响应编号与中文过滤检查。未启动或操作游戏；实际显示效果交给用户验证。

本机已备份并更新自己的插件 Lua；正在运行的游戏和桌面仍可能使用旧代码。用户保存并退出旧桌面程序，打开桌面 AbyssText-tooltip-fix-20261021 目录中的 EXE，连接已安装插件目录。在游戏先停止试译，再执行 cl_reloadlua，然后重新一键试译。不要同时运行两个工作台连接同一个插件目录。
