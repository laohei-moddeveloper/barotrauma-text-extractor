# 一键翻译 JSON 竞态修复与默认轻量采集

## JSON 弹窗

游戏通过 File.Write 更新交换文件时，文件可能短暂为空或只写了一部分。旧工作台在自动回传译文时读取 status.json，解析失败会走模态弹窗，打断桌面收发。

新版每次只尝试读取一个有大小限制的稳定快照。空内容、半截 JSON、非法编码、短暂占用或读取时变化会留待下一次轮询，不推进请求标记或 ACK 序号，不丢掉待确认的译文，也不在自动回传时弹模态框。连续 3 秒仍不可读时，状态栏显示具体文件名，恢复后清除。链接、过大输入和不支持的协议仍拒绝。

已有缓存、工程与语言设置无需删除；不要通过清空个人缓存来解决此报错。

## 默认轻量采集

上一轮只减少 Lua 内部工作，未验证真实游戏 C#→Lua Hook 的高频进入成本。本版默认不安装两个全局字体 DrawString、GUI.AddToUpdateList 和 GUITextBlock.Draw Hook。改为每步最多 8 个界面节点的持续分帧扫描，跳过隐藏子树，继续采集普通界面、预载定义及提示框；提示框 Hook 保留。旧页面恢复/缓存边界继续生效。

扫描只查已核对的 prefab 字段，不对所有类型试读相同的六个属性，也不对 LocalizedString 试读 RichString 专属属性；这些无效访问原先会产生大量托管异常。GUI.Children 的元素本身就是控件，去掉了额外 GUIComponent 字段探测。

在“翻译设置”可开启“兼容采集特殊绘制文字”。兼容模式恢复原有高频绘制 Hook，覆盖游离弹窗/自绘文字等路径，但可能导致掉帧。更改后在游戏停止并重新开启试译才能切换。设置本身不会发送翻译请求。

轻量模式不是相同覆盖范围下的零成本替代。自绘文字、树外控件以及每帧由 TextGetter 覆写的文字可能漏采或需等待原生语言键刷新；超大树的后部会等待扫描，仍有 3000 节点/控件边界。需要这些路径时由用户选择兼容模式。不承诺全覆盖或所有卡顿都消失。

## 更新及核验

更新工作台和自己的配套插件后，由用户在安全时机重载/重启游戏。旧缓存无需重导入。新版 status.json：

- runtime_build：snapshot-native-fix-20261023
- capture_mode：native（轻量）或 compatibility（兼容）
- render_hook_calls：轻量应为 0，不包括保留的提示框 Hook
- last_scan_nodes：分帧扫描节点数，通常每步不超过 8

工作台状态栏会显示“轻量采集”或“兼容采集”。可在相同页面对比两种模式；若轻量仍卡，请记录卡顿是否与语言资源刷新同步，以及 native 模式是否确实生效。兼容模式的流畅度不能用轻量模式的 Hook 数代替验证。

游戏 Timer.GetTime 基于 Timing.TotalTime，不是一次回调内不断前进的墙钟。这里没有用它伪造“每帧 1ms”保证，仍需真实帧时间验证。单次语言包加载、布局、getter、其他模组和后台预载仍可能卡顿。
