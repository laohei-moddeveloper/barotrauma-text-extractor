# 译潜 AbyssText 0.2.0-rc4 候选版安装与边界

此包用于用户验收，不是已通过实机验收的正式版本。仅在任务分支和私有 Actions 附件交付；不发布公开 Release 或创意工坊。源码、Windows、插件包通过同目录 SHA256SUMS.txt 校验，Windows 包内 VERSION.txt 标明构建源码提交。Windows x64 不需安装 Python、模型或填写 API。

## 明天本机操作（2026-10-22，香港时间）

1. 当前本机安装、运行的仍是 rc2；此前 rc3 仅构建验证，云端没有替换本机程序。先保存项目，停止游戏试译并退出旧工作台。备份自己的 EXE、自己的 AbyssTextLive 目录及其中 Live 数据；不要覆盖第三方模组或存档。
2. 从本次 Actions 附件下载 Windows ZIP、插件 ZIP、SHA256SUMS.txt。PowerShell `Get-FileHash .\AbyssText-0.2.0-rc4-Windows-x64.zip -Algorithm SHA256`，与清单核对，另两包同理。解压到新目录后运行新的 BarotraumaTextExtractor.exe，不要启动旧快捷方式。
3. 可先执行 `& '.\BarotraumaTextExtractor.exe' --check-online '.\online-rc4-new.json'`。输出必须是尚不存在的新路径；查看 ok、translation、issues 和耗时。该检查会向 MyMemory 发送固定 Open hatch；不打开游戏、不调用收费服务、不读取模型。网络/额度失败应保留报告，不代表插件已验收。
4. 只更新自己的 AbyssTextLive：游戏退出时，备份旧目录到 LocalMods 之外，使用插件 ZIP 的干净 AbyssTextLive 目录替换，再在工作台连接该目录。也可以先移走旧插件，再用 EXE“连接游戏→安装到 LocalMods”安装新目录；安装器不会覆盖已有目录。保留备份中的工程和缓存；不要直接搬回旧 requests/response/status/settings 文件。
5. 你自行启动游戏，确认 LuaCs 客户端及 AbyssTextLive 已启用。旧游戏会话需自行重新载入自己的 Lua（支持时 F3 `cl_reloadlua`），更稳妥的是重启游戏。工作台默认免费联网，选择 English→Simplified Chinese（或 Auto），连接插件后点击游戏一键试译。游戏语言应与目标语言一致；切换语言对须先停止再开始。
6. 人工检查物品/生物名称和简介、症状、任务/对话与提示框；检查已汉化内容保持、占位符/颜色/换行、下拉框、换回合继续、新提示框优先、停止恢复、再次启动缓存、断网恢复。记录截图、复现步骤、版本与自己的 translation-status.json 中错误，避免分享私密原文。没有实战数据前不要把隔离测试当作游戏通过。

## rc4 的修复

- 保留 rc3 的解释器 TLS 策略资源自动打包：修改过的 Python 缺少必须资源时构建直接失败，普通 Python 不要求 Codex 专属文件。不改证书内容，不关闭证书或主机名验证。TLS/证书错误不再作为超时重试。
- 单条失败不丢弃其他结果；本地缓存无法写盘仅告警，后续批次继续；损坏/格式不符缓存重新翻译。暂时网络错误同会话每条最多 2 次尝试、间隔 30 秒，不冻结其他正常条目；额度/403/429 使整个提供方冷却 1 小时。停止/重启试译可人工重试，仍受提供方实际额度限制。
- 单文件请求必须等桌面确认导入才可被替换，避免前一批丢失；确认后当前可见提示框仍可优先。响应校验会话和语言对；过期任务的结果、错误和完成通知不能污染新会话。桌面切换语言对暂停自动试译，等待游戏停止再开启产生新请求。停止前排队的启动回调不能在下一次启动中执行。
- 默认免配置 MyMemory 免费 HTTPS；已有中文在英文→中文模式跳过，既有译文不覆盖。游戏每批最多 8 条，桌面调度 4 条、最多 2 个联网请求；自定义 AI 批次同样最多 8 条。不新增模型或付费回退。

- Windows 回归中补正 UTF-8 文件读写契约；CLI 重定向输出明确使用 UTF-8，避免英文 Windows 控制台编码导致中文诊断异常退出。

## 覆盖和未覆盖

读取**已加载**的 Item/Affliction/Character/Mission/Job 公开 prefab 与语言表：名称、简介、可访问的症状说明、任务成功/失败消息等；GUI 控件、原生字体绘制与 tooltip 捕获当次显示的文本，可包含任务和对话。预加载按有界步骤持续进行，当前可见内容优先，但不能抢占已发出的 HTTP 请求。大语言表、网络延迟、分段请求、额度和重试都会使完成需要时间。

不保证：未加载/未触发内容、图片中文字、自定义绘制/复杂动态 getter、全部对白路径、特殊颜色索引字体重载、第三方 Hook 冲突或全部布局。只有普通范围汉字的保守跳过规则；混合中英整条保留，可能留下其中英文；稀有扩展字符不能据此保证识别。机器翻译还需语义校对。同文异义的字面量替换可能需工作台拆分/人工适配；语言键和字面量替换不是完整运行时语义分析。

预加载每步最多访问 32 个 prefab，每个 prefab 可读取多个字段；语言表及队列缓冲分步处理。队列/已见身份/控件/磁盘缓存有限额（10000/20000/3000/10000 条或缓存 8 MiB），达到限额会有遗漏；桌面工程与回传词典随已导入内容增长，不能宣称恒定内存。未测真实帧时间、FPS、UI 视觉、LuaCs 的真实游戏接口绑定及服务日额度耗尽后的实网恢复。免费服务会收到原文及语言对，别发送私密模组文本。

## 验证与恢复

具体结果及构建提交以 Actions frozen-checks.json、frozen-online.json 与最终报告为准。模拟服务、源码 Python、打包 EXE 和真实游戏是四个不同层次。普通 Windows CI 解释器的实网成功，不等于已在用户修改过的 Python 上重新打包验证 rc4；那个环境已由用户在 rc3 证明过，rc4 资源探测另有隔离回归。

回退时保存工程并退出新工作台、停止试译；恢复自己的 EXE/插件备份并重新加载客户端，必要时重开缓存界面。云端没有操作你的桌面或更新你的本机。
