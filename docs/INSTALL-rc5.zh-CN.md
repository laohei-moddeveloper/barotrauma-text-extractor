# 译潜 AbyssText 0.2.0-rc5：速度、术语与运行负担

这是 rc4 的后续候选版。Windows 工作台和自己的 AbyssTextLive 插件需一起更新才能使用增量协议；旧插件仍可走完整回传兼容路径，但没有该项减负效果。云端没有替换你本机的程序，不替换游戏 DLL、不改第三方模组或存档；游戏验收仍由你自行进行。此分支不自动发布 Release/工坊或合并 main。

## 使用与免费渠道

Windows 包无需 Python、API 密钥或模型。默认 MyMemory 免费接口；工作台“翻译服务设置”可选 **Google 网页兼容（实验）**。Google 直接连接 translate.googleapis.com，无中间转发站，但它不是有免费额度保障的官方付费 API 产品，大陆可能无法直连，接口也可能改变或限流。MyMemory 同样有每日额度和服务质量限制。只向你选择的一个渠道发送文字，没有自动跨渠道重试/隐私扩散，不调用收费接口或下载模型。

设置渠道会停止旧渠道后续工作，已发出的 HTTP 可能要等响应/超时；旧渠道晚到结果不填进新渠道任务。切换只影响尚未完成的文字，已保存/已生成译文不自动覆盖。若要重译某条已有草稿，先自行保存备份，再在工作台清空该条草稿或改译文。源/目标语言切换仍需游戏停止再开启。远程自定义 AI 是单独的可选模式，本轮没有调用它。

## 三项改进

- **少发请求、少空等**：136 个核对过的原版短术语和有限医学整句模板可直接复用；项目术语表真正接入免费翻译。整句保留语境并保护术语/格式；服务损坏保护标记时保守分段，不能保证所有句子都只发一次。全文及片段缓存按渠道、语言对、语境和有效术语隔离，并发重复片段合并；磁盘缓存仍有 10000 项/8 MiB 上限。两个请求槽位滚动运行，后台队列最多 16 条，可见文字优先；不是每 4 条等齐才开始下一批。游戏请求和回传每包仍最多 8 项。短的结构化名称可把最多 4 条合为一次 HTTP（总计不超过 480 UTF-8 字节），只取已排队的同优先级名称，不等待凑批。简介/任务/对白、带格式或术语保护的文字不混入；边界缺失/重复/错序时逐条回退，限流/传输失败不追加回退请求。
- **游戏用词更一致**：原版物品/生物/症状/设备/职业的短术语附语言键及参考文件哈希，避免把 Coilgun、Mudraptor、Husk infection 按普通网页词义翻译。用户术语优先。Barotrauma 等歧义词需症状/职业等明确语境，且不能用症状译名全局替换游戏标题。未知模组新词仍需导入术语或人工校对；免费机器翻译不是游戏语义模型，不承诺完整对白正确。窄医学模板只匹配完整已知病症与药物指令，不猜未知病名或药物。
- **少重建、少主线程工作**：新增游戏文字逐条合入项目；空闲无变化不重建 XML/反复写响应。新插件协商每包最多 8 项的带序号增量，确认收到后才发下一包，保留重连/会话隔离和旧协议兼容。普通字面量不刷新语言资源；原生语言键 XML 最多每 2 秒合并刷新。控件采集每步最多 32 节点，队列选择每次最多访问 64 个节点，不再排序整个待翻译队列；刷新队列不被新响应不断重置。桌面事件每轮最多 64 条并设时间预算，诊断/缓存写盘合并，避免缓存命中突发时持续刷盘。

轮询间隔缩到 250 ms 以减少等待；读取文件有元数据缓存，响应本身保持小包。它仍有文件 I/O 和 Lua Hook 成本，不宣称零开销。引擎属性 getter、语言资源重载、第三方 Hook、字体布局和游戏其余系统仍可能卡顿；没有真实帧时间证据时不宣称提升了多少 FPS。

## 安装、核验与回退

1. 保存当前工程、停止试译并退出旧工作台。备份自己的 EXE 和 AbyssTextLive（含自己的 Live 数据），把旧插件备份放到 LocalMods 外；不动其他模组/存档。
2. 下载最终 CI 的 Windows ZIP、插件 ZIP 和 SHA256SUMS.txt，PowerShell `Get-FileHash 文件名.zip -Algorithm SHA256` 核对。解压 Windows 包到新目录并确认启动的是 rc5；更新自己的插件或用工作台安装到新目录，安装器拒绝覆盖已有目录。不要把旧 requests/response/status/settings 文件搬回新插件。
3. 可先用 `BarotraumaTextExtractor.exe --check-online 新的报告.json` 验证默认渠道；Google 用 `--check-online 另一个新报告.json --online-channel google`。两者使用固定 Open hatch 样本，只是实际联网验证，不是游戏验收。必须使用不存在的新路径。
4. 由你自行启动游戏或重新载入自己的 Lua；工作台连接新插件，选择语言与渠道，再一键试译。检查物品/生物、症状、任务/对话、提示框、已汉化文本、占位符/颜色/换行、换回合继续、停止再开、断网恢复和旧译文修正。关注实际滚动/打开背包/新任务的帧时间，反馈版本、复现和截图，不发私密原文。
5. 回退需退出新工作台并停止试译，恢复自己的 EXE/插件备份后自行重载客户端。匹配版本很重要；只更换 EXE 或只更换 Lua 不代表完整启用了本轮优化。

源码、Windows、插件包、SHA256、CI/实网样本和合成前后对比见任务分支 `research/handoffs/abysstext-rc5-20261022-report.zh-CN.md`。合成请求数、字节数和耗时不等于整局速度或 FPS；6 句开发回归的术语命中不是全语义准确率或独立盲测。图片、自定义绘制、未加载内容、全部对白路径和同文异义仍有边界。未知扩展汉字及混合中英的保守跳过行为沿用 rc4。
