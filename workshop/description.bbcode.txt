[h1]点一次，让支持的游戏内英文变成中文[/h1]
泥偶迅猛龙汉化（AbyssText）包含两个配合使用的部分：[b]游戏内实时汉化插件[/b]与[b]游戏外翻译工作台[/b]。游戏里点击一次试译，工作台在后台处理待翻译文字，已就绪的译文直接显示在支持的原生名称、简介、控件和提示框里。无需把英文一条条复制出去，也不用反复为同一个已翻译物品点击按钮。

[h2]游戏内能做什么[/h2]
[list]
[*]支持已加载物品、生物、症状、职业、任务等定义中的可读取名称和介绍，以及已适配的原生控件、语言键和富文本提示框。人物物品栏和潜艇编辑器已有真实游戏显示结果。
[*]开始后持续采集、翻译和接收结果；换回合会继续扫描新加载的定义。能够预采集已加载内容，不必每次出现同一个物品都重新点击。未加载模组不会扫描。
[*]结果更新支持的原生文字显示，不额外铺一层翻译字幕，不改其他模组源码或原游戏 DLL。再次点击停止试译，可恢复本插件替换的显示；缓存界面可能需要重新打开。
[*]已有中文保守跳过，已有译文不会自动覆盖。保留可识别的颜色标记、数字模板和占位符；复杂自定义格式仍可能不受支持。
[/list]

[h2]先看这里：需要桌面工作台保持运行[/h2]
游戏插件负责采集和应用文字，翻译由 Windows 工作台完成。[b]仅订阅、只启用插件而没有运行并连接工作台，不会自行完成联网翻译。[/b]

[h2]安装与首次使用[/h2]
[olist]
[*]按 LuaCs 官方说明安装并启用 [url=https://steamcommunity.com/sharedfiles/filedetails/?id=2559634234]LuaCs 客户端[/url]，然后在游戏模组列表启用本插件。插件内部名称目前仍含“AbyssTextLive / 译潜本地实时试译”。旧 LocalMods 版与本工坊版请只启用一个。
[*]在本条目的已下载文件夹打开 [b]Workbench[/b]，把其中 [b]AbyssText-0.2.0-rc5-Windows-x64.zip[/b] 解压到普通文件夹，运行 [b]BarotraumaTextExtractor.exe[/b]。Windows 包无需安装 Python。EXE 是独立桌面程序，不是要放进 Lua/Autorun 的游戏脚本。
[*]工作台点“连接游戏 → 连接已安装插件”，选择[b]你实际启用的这份 AbyssTextLive 的根目录[/b]，即同时包含 filelist.xml、Lua、Live、Workbench 的文件夹。不要选上级总目录，也不要连接旧插件副本。
[*]源语言选 English 或 Auto，目标语言选 Simplified Chinese；建议游戏语言也设为简体中文。默认免费联网无需账号、密钥或模型。保持工作台运行，回到游戏点击右上角“译潜 · 一键试译”，等待已收译文数量增加。
[*]以后在本次客户端会话中保持试译开启即可；首次排队内容较多时要等待。手动停止或重启客户端后需重新开启。切换源/目标语言时，先在游戏停止，再重新开始。
[/olist]
找不到下载目录时，可查看游戏的 WorkshopMods/Installed/3823861796，或 Steam 库的 steamapps/workshop/content/602960/3823861796。不同安装方式可能使用不同位置；连接目录以游戏实际启用项为准。

[h2]游戏外：提取、翻译、校对、导出[/h2]
不玩游戏时也可独立使用工作台：只读扫描模组 XML/Lua/C# 中可识别的文字，将完全相同的原文归并并保留文件、键和语境；支持分类、搜索、中英界面切换、源/目标语言选择、编辑、备注、术语表、翻译记忆、格式检查与预览。可保存工程、导出 CSV/原生语言包或受支持位置的模组副本。静态扫描不会执行被扫描的脚本；语言包和静态提取都不等于所有硬编码内容均可覆盖。

[h2]联网渠道、等待与翻译质量[/h2]
内置 MyMemory 免费接口，以及可选择的 Google 网页兼容实验渠道，无需自行下载模型或配置 API 密钥。Google 实验接口并非有稳定性保证的付费官方 API，大陆可能无法直连；MyMemory 有每日额度，可能限流。只向你选定的渠道发请求，不自动切到另一家，也不自动购买服务。免费模式会发送待译原文片段和语言对到对应第三方服务，请勿拿它处理私密文本。

首次翻译需要时间；缓存、术语和有界队列可减少重复工作，但[b]“一键”指启动方式，不代表所有文字瞬间翻译完成[/b]。如果已提交很多而游戏已收译文为 0，先看工作台的失败原因及所选渠道。本机这次 MyMemory 限流，手动选择 Google 后恢复；其他电脑的网络条件可能不同。已有本地模型/自定义兼容服务属于可选高级模式，不是使用内置联网翻译的前提。

我们会随模组更新持续完善游戏术语、模组词汇和语境处理，让翻译质量不断提高。桌面工作台也支持编辑、校对和导入自己的术语表。当前版本生成机器翻译草稿，部分语境仍需校对；它适合补充未汉化内容、快速理解英文和制作翻译稿，也可与模组作者认可的人工汉化配合使用。

[h2]覆盖边界与恢复[/h2]
图片里的文字、自定义绘制、未适配接口、未触发的动态内容或尚未排到的文字可能仍显示原文；不承诺全部任务和对白无遗漏。网络失败、额度、字体和其他 Hook 也会影响结果。客户端插件只改变本机显示，不会把你的译文自动同步给其他玩家；并非服务端汉化补丁。

停止：再次点试译按钮，或 F3 执行 abyss_stop。开启命令为 abyss_translate。关闭后必要时重新打开缓存界面；要卸载则禁用本插件并重启客户端。更新前保存自己的工作台工程，备份自己旧插件的 Live 数据；不要同时启用多个副本。
